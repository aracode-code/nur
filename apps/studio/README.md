# @nur/studio — UX Gate A preview shell

**Status:** sementara. Folder ini memuat shell web untuk review visual Gate A: Beranda, Jelajahi, Serial, Tersimpan, Profil, dengan data demo berlabel.

**Penting:** ini **bukan** Creator Studio final. HLD menetapkan aplikasi pengguna sebagai mobile (React Native) dan Creator Studio sebagai web terpisah. Shell ini dipakai lebih dulu karena Gate A membutuhkan preview visual yang dapat dijalankan di browser. Saat Phase 5 dimulai, halaman consumer dipindahkan ke aplikasi mobile dan folder ini menjadi Creator Studio.

Aturan:

- Data demo tidak boleh menjadi data produksi.
- Tidak ada aksi yang mengaku berhasil tanpa API.
- Token desain berasal dari `@nur/design-tokens`.
- Perubahan visual harus dibandingkan dengan `docs/design/NUR_UX_UI_Design_Prototype.html`.
