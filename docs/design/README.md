# NUR UX/UI Design Reference

`NUR_UX_UI_Design_Prototype.html` is the approved visual reference for implementing the NUR frontend.

Read `docs/architecture/HLD.md` sections 28–29 before implementing frontend pages. Preserve the design direction and document approved deviations in `UX_UI_IMPLEMENTATION_SPEC.md`.

The prototype is for visual/interaction reference only. Demo data and demo actions are not production data or backend functionality.
